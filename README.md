# MSc Thesis: AGN jets in galaxy groups and clusters

Contains scripts I wrote for my master's thesis.

Written at the Leibniz Institute for Astrophysics Potsdam (AIP).

## Contents

All scripts used for the thesis are in `ThesisScripts/Chapters/`, sorted by thesis chapter and section.

| Folder | What's in it |
|---|---|
| `Numerical_Methodology/` | Initial conditions, comparison of setup with IllustrisTNG. |
| `Results/3run/` | Analysis for galaxy group halos. |
| `Results/1e14_3run/` | The same analysis for the cluster halo. |
| `Results/groups_vs_clusters/` | Group vs. cluster comparison. |
| `Results/selfreg_3jet/` | Analysis of a self-regulated setup with Bondi accretion for galaxy groups. |
| `Results/longrun_vs_fidself/` | Comparing the self-regulated setup with a single outburst jet. The power of the single outburst jet is equal to the average power of the self-regulated jet over a 1 Gyr runtime. |
| `Results/slow_and_steady/` | 10<sup>45</sup> vs. 10<sup>46</sup> erg/s jets with the same total energy, but different powers and active times. |
